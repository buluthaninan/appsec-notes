# AppSec Notes

I'm a software engineer with 4+ years of experience building web and mobile
apps with .NET, React and Flutter, now moving into Application Security.

I've always been drawn to the other side of software: the flaw nobody noticed,
the way in that shouldn't exist, the thing that breaks when you push it a
little. (Growing up on hacker movies probably helped.) This repo is where I
turn that curiosity into a skill.

My goal is to be someone who can both find vulnerabilities and show developers
how to prevent them. That's why every topic here covers what the vulnerability
is, how I find it, the labs I solved, and how I'd prevent it as a developer.

## Current focus
Working through PortSwigger Web Security Academy toward the
Burp Suite Certified Practitioner (BSCP) exam.
